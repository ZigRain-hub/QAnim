## Инструкция

Запускаем QAnim-installer.exe (он устанавливает анимации в терминал)
Запускаем любой удобный терминал
Пишем любой понравившейся анимаций:
Список анимаций:
cava
lava
cmatrix
pclock
pipes
pixel
rain
Как регулировать анимации?
После запуска QAnim-installer.exe появиться ярлык на рабочем столе (это и есть приложение для изменения анимаций)
НЕРЕКОМЕНДУЕТСЯ но можно, я бы не советовал запускать файлы с папки payload так как они предназначены ТОЛЬКО для терминала (даже .exe там лежат открывать не советуется)
Как удалить?
(Пример:(C:\Users\Admin\) начало может отличаться
C:\Users\Admin\AppData\Local\QAnim (папку QAnim можно удалить - это и есть само приложение)
